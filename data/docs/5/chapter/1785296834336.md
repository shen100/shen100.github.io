# 系统维护
## 每日要运行的脚本
### 数据源
| 脚本 | 说明 |
| ------- | ------- |
|  server/scripts/sync_data/save_kline_day_to_db.js  |  把所有股票的历史K线(日线)存入数据库 |
|  server/scripts/sync_data/save_stock_detail_to_db.js  |  把所有股票的详细信息存入数据库 |
|  server/scripts/sync_data/save_tushare_daily_basic_to_db.js  |  把每个公司每日的市值存入数据库 |

### 统计分析
| 脚本 | 说明 |
| ------- | ------- |
| server/scripts/statistics/stat_daily_up_count.js  |  统计每日上涨股票数(相对于前 N 个交易日的最高价) |
